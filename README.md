# LSCT-PHIQNET-TORCH

Unofficial Pytorch implementation of the ACM MM'21 paper [Long Short-term Convolutional Transformer for No-Reference Video Quality Assessment](https://dl.acm.org/doi/abs/10.1145/3474085.3475368)

The official version is at [https://github.com/junyongyou/lsct_phiqnet](https://github.com/junyongyou/lsct_phiqnet)

The provided weight are transfered from the official TF-Keras weight file.
